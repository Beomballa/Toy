# AGENTS.md

## 적용 범위

`Front` 프론트엔드 작업에 우선 적용합니다.

---

## Frontend 규칙

기존 화면 구조를 유지합니다.

기존 id, name, class 변경은 사용자 요청이 있는 경우에만 수행합니다.

기존 이벤트 흐름을 유지합니다.

기존 Alert, Confirm, Modal 유틸리티를 우선 사용합니다.

기존 Axios 호출 패턴을 유지합니다.

화면 구조 변경보다 기존 동작 유지와 최소 수정 원칙을 우선합니다.

동일한 화면에서 이미 사용 중인 버튼, 배지, 카드, 테이블 패턴이 있으면 우선 재사용합니다.

---

## IBSheet 규칙

기존 SaveName 변경 금지

기존 Column Key 변경 금지

기존 RowData 구조 변경 금지

기존 Event 함수명 변경 금지

Header 이벤트 및 기존 시트 동작을 유지합니다.

IBSheet 응답 구조와 서버 응답 필드는 일치해야 합니다.

---

## 테스트 / 검증 보강

화면 작업 완료 후 화면 동작 기준으로 검증합니다.

자동 테스트 실행이 어려운 경우 수동 검증 포인트를 명확히 정리합니다.

실행 환경 문제로 테스트나 브라우저 검증을 수행하지 못한 경우 반드시 보고합니다.
