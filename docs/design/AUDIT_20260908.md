## 현재 확인

- 홈: 배너 한글 단어 분리 확인. 제목 크기·줄바꿈 규칙 수정.
- 상품 목록: 검색 제어 5개 대비 4열 grid로 초기화 버튼 줄바꿈 확인. 5열 및 중간 폭 재배치 수정.
- 상품 상세: 상품명 대신 전시 문구 표시, 경로 특수문자 이중 변환 확인. 실제 상품명 및 출력 지점별 escape 적용.
- 관리자 교환반품: 1~7페이지 고정 코드로 8페이지 이후 이동 차단 확인. 이동 창·처음/마지막 및 빈 마지막 페이지 복구 수정.
- 홈 헤더와 다른 페이지 헤더는 별도 HTML이며 메뉴·관심 링크가 다름. 통합 범위 추가 검토 필요.
- 프론트 CSS 19,318줄. 큰 파일이라는 이유만으로 삭제하거나 결함으로 판정하지 않는다. 실제 cascade·사용 선택자부터 조사한다.
- 상세 Signal, 운영 용어, 홈의 여러 보조 도구는 고객 쇼핑 흐름 기준 재정리 필요.
