# NOREN Components

## Store Shell

데스크톱은 유틸리티, 브랜드/주요 탐색, 카테고리의 3개 행을 사용한다. 모바일은 56px 브랜드 행과 펼침 메뉴로 단순화한다. 검색은 모든 보조 화면에서 같은 전체 화면 다이얼로그를 사용한다.

## Buttons

- Primary: 잉크 배경, 흰색 텍스트. 화면의 핵심 행동 하나에 사용한다.
- Secondary: 흰색 배경, 경계선. 관심, 비교, 취소에 사용한다.
- Tertiary: 배경 없는 텍스트. 더보기와 부가 이동에 사용한다.
- Destructive: 테라코타 텍스트 또는 배경. 삭제 확인 단계에서만 사용한다.

버튼 라벨은 명사보다 행동을 사용한다. `확인` 대신 `주문하기`, `저장하기`, `다시 불러오기`처럼 결과가 드러나야 한다.

## Product Card

이미지, 브랜드, 상품명, 가격, 배송/재고 보조 정보 순서로 구성한다. 카드 전체를 상세 링크로 만들되 관심 버튼은 독립 버튼으로 유지한다. 이미지 비율은 1:1, 상품명은 최대 2줄, 가격은 한 줄이다.

## Product Rail

제목과 설명은 왼쪽, 더보기와 이동 제어는 오른쪽에 둔다. 정렬, 일괄 저장, 복사는 오버플로 메뉴로 이동한다. 모바일에서는 설명 다음 줄에 제어를 두고 레일은 가로 스크롤을 사용한다.

## Form

라벨, 입력, 도움말, 오류 순서로 배치한다. 라벨은 숨기지 않으며 placeholder를 라벨 대신 사용하지 않는다. 오류 발생 시 입력의 `aria-invalid`와 상태 메시지를 함께 갱신한다.

## Overlay

검색은 dialog, 필터는 drawer, 짧은 결과 알림은 toast를 사용한다. 모든 overlay는 열린 요소로 초점을 이동하고 닫힐 때 호출 버튼으로 돌려보낸다.

## Data State

로딩은 뼈대 또는 짧은 진행 문구, 빈 결과는 이유와 복구 행동, 오류는 재시도 버튼을 제공한다. 결과가 없는 상태에서 빈 카드 외곽선이나 가짜 상품을 노출하지 않는다.
