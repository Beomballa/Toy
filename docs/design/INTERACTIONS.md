# NOREN Interaction Contracts

## Navigation

- 추천, 랭킹, 빠른배송, 신상은 `/front/collections/*` 독립 화면으로 이동한다.
- 홈의 상품 더보기는 전체 카탈로그 내부 앵커가 아니라 해당 컬렉션으로 이동한다.
- 상세의 카탈로그 복귀는 사용자가 진입한 컬렉션 정보를 사용할 수 없으면 추천 컬렉션으로 이동한다.

## Search

1. 검색 버튼이 dialog를 연고 입력으로 초점을 이동한다.
2. Enter 제출 시 공백을 제거하고 상품 탐색 URL로 이동한다.
3. Escape 또는 닫기 버튼으로 닫고 호출 버튼으로 초점을 복원한다.
4. 빈 검색어는 이동하지 않고 입력에 초점을 유지한다.

## Product Selection

옵션 선택 후에만 수량과 주문 행동을 활성화한다. 재고가 0인 옵션은 선택할 수 없고 이유를 읽을 수 있어야 한다. 바로 구매는 장바구니 상태를 거치지 않고 체크아웃 입력으로 이동하되 중복 요청을 막는다.

## Authentication

로그인과 회원가입 탭은 `aria-selected`, 폼 `hidden`, 제목과 설명을 동시에 갱신한다. 유효성 검사를 통과한 뒤에만 요청하고, 요청 중에는 제출 버튼을 비활성화한다. 성공 후 안전한 `/front` 내부 URL만 허용한다.

## Feedback

짧은 저장 결과는 toast, 입력 오류는 inline status, 네트워크 오류는 재시도 가능한 상태 영역으로 전달한다. 자동으로 사라지는 toast는 최소 4초를 유지하고 같은 내용이 반복되면 타이머를 갱신한다.
