# NOREN Screen Specifications

## Home

프로모션 1개, 카테고리 바로가기, 신규 드롭, 빠른배송, 추천 상품, 에디토리얼 순서로 구성한다. 검색과 정렬 도구는 헤더 검색 또는 독립 상품 탐색 페이지에서 제공한다. 개인 보드는 요약 카드만 노출하고 상세 관리는 MY로 연결한다.

## Product Discovery

페이지 제목과 결과 수, 검색/정렬, 활성 필터, 4열 상품 그리드, 서버 페이지 이동 순서다. 데스크톱은 향후 필터 사이드바를 수용할 수 있고, 모바일 필터는 드로어로 전환한다. 결과 헤더는 고정하지 않는다.

## Product Detail

데스크톱은 좌측 이미지와 우측 구매 패널의 2열 구조다. 우측 순서는 브랜드/상품명, 가격/재고, 옵션, 수량, 주요 구매 행동, 관심/비교다. 분석 지표와 복사 기능은 접힌 부가 정보로 이동한다. 모바일은 이미지 다음에 구매 정보가 이어지며 주요 구매 행동만 하단 고정 바에 둘 수 있다.

## My Page

회원 요약, 주문, 후기, 저장 활동 탭 순서다. 위험한 전체 초기화는 페이지 하단의 별도 영역에 둔다. 일괄 처리 버튼은 선택된 항목이 있을 때만 강조한다.

## Login / Sign Up

동일한 인증 셸을 공유하되 URL과 초기 탭에 따라 하나의 폼만 주 작업으로 보인다. 데스크톱은 브랜드 설명과 폼의 2열, 모바일은 설명을 축약한 1열이다. 비밀번호 요구사항과 서버 오류는 입력 가까이에 표시한다.

## Responsive Matrix

| Width | Grid | Header | Overlay |
| --- | --- | --- | --- |
| 1200px+ | 상품 4열 | 3행 | 중앙 modal |
| 768~1199px | 상품 3열 | 2~3행 | 중앙 modal |
| 360~767px | 상품 2열 | 1행 + 펼침 | 전체 화면 |

모든 화면은 320px에서 콘텐츠가 잘리지 않아야 하며, 기본 검증 폭은 Chrome 1280x900과 Pixel 7이다.
